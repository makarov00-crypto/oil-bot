# Исправление календарного окна направления — 26 ноября 2026

Исходная версия: `0a637f8`. Область изменения: многодневный фильтр направления,
общий для всех инструментов и обеих сторон. Окна 12/24/48/72 часа теперь выбираются
по времени закрытия часовых свечей. Ночные/выходные перерывы входят в окно.
Пороги признаков и условия часового сигнала не подбирались по результатам проверки.
Дополнительного исключения для нефти не добавлено.

## Метод

Получены закрытые часовые свечи брокера для всех 14 активных инструментов за
22 октября — 26 ноября 2026, до 16:00 МСК. Оценка сигналов: 1–26 ноября,
история до ноября служит прогревом индикаторов. Для каждого решения индикаторы
пересчитываются на доступном к этому моменту окне 241 календарный час, как в боте.
Изменяется только допуск многодневного фильтра; часовой сигнал одинаков для старого
и нового вариантов. Последовательные одинаковые сигналы с одинаковым статусом
допуска объединены в эпизод. Решения до 09:00 МСК исключены.

Движение через 4/8 календарных часов измерено в направлении сигнала и нормировано
на средний диапазон свечи при входе. При отсутствии свечи закрытия в пределах
одного часа после горизонта результат не рассчитывается. Это диагностика допуска,
не воспроизведение торгового счёта: позиции, выходы, комиссии, очередь капитала,
ограничения повторного входа и исполнение не моделируются. Эпизоды могут пересекаться.

## Воспроизведение

`scripts/audit_calendar_regime.py` принимает `--candles` (JSON: инструмент и свечи
по каждому тикеру), `--baseline-core` (файл reversal_core.py версии 0a637f8),
`--output` (подробный JSON результатов). Скрипт не подключается к брокеру и
не отправляет заявки. Результаты не доказывают рост будущей прибыльности:
исправляется неверная единица измерения времени, а не оптимизируется результат.
